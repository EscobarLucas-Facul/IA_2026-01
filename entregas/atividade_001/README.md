# Pipeline de Classificação de Pinguins 🐧

Este projeto foi desenvolvido para a disciplina de Inteligência Artificial. O objetivo é criar um pipeline profissional para classificar espécies de pinguins utilizando o dataset Seaborn.

## 🛠️ Tecnologias Utilizadas
* Python
* Pandas & Seaborn (Análise de Dados)
* Scikit-Learn (Machine Learning)
* Matplotlib (Visualização)

## 📋 Estrutura do Projeto
1. **Diagnóstico:** Análise de tipos de dados e tratamento de missing values.
2. **Pipeline:** Automação de pré-processamento (SimpleImputer, StandardScaler, OneHotEncoder).
3. **Modelagem:** Comparação entre um Baseline (Regressão Logística) e uma Melhoria (Random Forest).
4. **Avaliação:** Uso de Matriz de Confusão e métricas de Precision/Recall.

## 📊 Resultados
Ambos os modelos atingiram uma acurácia de **98,55%**, demonstrando alta eficiência na separação das espécies Adelie, Chinstrap e Gentoo.

## 🧪 Como executar
Basta abrir o arquivo `.ipynb` neste repositório através do Google Colab ou Jupyter Notebook.
